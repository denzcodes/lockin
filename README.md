# LockIn 🔒

A distraction-free sprint timer built for deep work, coding marathons, and zero-procrastination study sessions.

## Features
- **Three Sprint Modes:** *Locked In*, *Quick Breather*, and *Recharge* with dynamic accent colors.
- **Custom Durations:** Adjust session lengths via the settings modal (saved automatically to `localStorage`).
- **Live Tab Countdown:** Track your remaining sprint time directly from your browser tab.
- **Zero-Dependency Audio Chime:** Synthesized completion alert powered by the native Web Audio API.

## Tech Stack
- HTML5 (`<dialog>` modal)
- CSS3 (Custom Properties & Flexbox)
- Vanilla JavaScript (ES6+, Web Audio API, LocalStorage)
